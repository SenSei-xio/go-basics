### 原文（带注释）

```go
package main

import "fmt"

// ── 注释掉的那段：递归写法（旧版，留着对比）──
/*func fibo(n int) int {
	if n == 0 || n == 1 {      // 不是 0 就是 1（|| 是"或者"）
		return 1
	}
	return fibo(n-1) + fibo(n-2)   // 自己调自己：前两个数相加
}
func main() {
	for i := 0; i < 20; i++ {      // 从 0 开始，跑 20 次
		fmt.Println(fibo(i))
	}
}
*/

// ── 现在用的那段：循环写法 ──
func fibo(n int) int {             // 定义一个叫 fibo 的函数，收一个 int，返回一个 int
	if n == 0 {
		return 0                   // n 是 0 就直接给 0
	}
	if n == 1 {
		return 1                   // n 是 1 就直接给 1
	}
	a, b := 1, 1                   // 一次声明两个变量：a 和 b 都是 1
	for i := 2; i <= n; i++ {      // i 从 2 走到 n（含 n），每轮 +1
		c := a + b                 // c = 前两个数相加
		a = b                      // 先把旧的 b 挪给 a（注意顺序！）
		b = c                      // 再把新的 c 挪给 b
	}                              // 这两个盒子往前滚，滚到第 n 个数
	return b                       // 最后 b 里就是答案
}

func main() {
	for i := 1; i < 10; i++ {      // 从 1 数到 9
		fmt.Println(fibo(i))       // 打印 fibo(1) 到 fibo(9)
	}
}
```

**实际输出**：`1 2 3 5 8 13 21 34 55`

### 这 40 行在干嘛（我自己讲的）

两种算法算同一串数：

- **注释掉的那段（递归）**：`fibo(n)` 等于 `fibo(n-1) + fibo(n-2)`，一直往前拆，拆到 0 或 1 停。写法短，但算 `fibo(30)` 要重复算几百万次。
- **现在这段（循环）**：不往前拆，从 `a=1, b=1` 开始往后滚，滚 `n` 轮就到答案。两个变量 `a`、`b` 像两条腿交替往前迈。

### 哪个设计看不懂

1. **`a = b` 和 `b = c` 凭什么不能换顺序？**
   一开始我以为就是两个赋值，随便写。实跑才知道：换顺序 `fibo(9)` 会从 55 变成 **256**。
   因为 `b = c` 先跑的话，`b` 先变成新值，`a = b` 拿到的是新值 → 两个盒子永远一样，滚不下去了。
   **记法：先把旧的 b 挪给 a，再把新的 c 挪给 b。**

2. **`a, b := 1, 1` 这一行是什么意思？**
   一次声明两个变量，等于 `a := 1` 加 `b := 1`。`:=` 左边可以放多个名字，右边给同样多的值，一一对应。

### 学到一个什么写法

**"两个变量交替滚动"**这种模式：

```go
c := a + b
a = b
b = c
```

以后凡是"下一个数 = 前两个数算出来的"，比如菲波那契、爬楼梯、爬楼梯变体，都是这个骨架。
